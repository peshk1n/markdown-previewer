# Markdown Previewer

Browser-based Markdown editor built with **React + Vite**.  
Live preview your Markdown and export as **PDF** for notes or docs.  

Run locally:  

```bash
git clone https://github.com/peshk1n/markdown-previewer.git
cd markdown-previewer
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.
